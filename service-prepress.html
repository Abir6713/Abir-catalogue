Prepress Preparation

Starting at ₦90,000

What It Entails

Prepress is the last stop before the press runs. Everything designed so far — the text, images, cover — has to be turned into a print-ready file that the printer can open, check, and press without a single query.

Most problems in printing don't happen on the press; they happen because the file wasn't prepared properly. Wrong image resolution, missing fonts, wrong colour mode, invisible bleed. Prepress catches all of it.

What's Included

  • Page size check: Confirm the document matches the printer's required trim size.
  • Bleed and crop marks: 3mm bleed added; crop marks positioned correctly.
  • Image resolution: Every image verified at 300 DPI minimum; low-res images flagged.
  • Colour mode: All colours converted to CMYK; spot colours checked.
  • Font embedding: All fonts embedded or converted to outlines.
  • Transparency flattening: Any transparency flattened to prevent print errors.
  • PDF/X export: A print-standard PDF/X file suitable for any printer.
  • Pre-flight report: A checklist of everything verified — you receive a copy.
